# Paper Reading

[打开论文索引](https://get1024.github.io/paper-reading/)

收录已读论文的中英对照批注和论证分析。索引支持搜索论文标题、简介和关键词，默认按标题 A–Z 排序，也可切换到 Z–A。

新增论文时，把 HTML 文件放在仓库根目录，在 `index.html` 的论文列表中加入卡片。封面放在 `assets/`。推送到 `main` 后，GitHub Pages 会自动发布。
